🍕 Pizza Sales Analysis Dashboard | Power BI

📌 1. Project Title / Headline

🍕 Pizza Analytics: Interactive Sales Performance Dashboard

A dynamic, interactive Power BI dashboard designed to analyze pizza sales performance, revenue trends, customer ordering patterns, and product popularity through data visualization and business intelligence.

🎯 2. Short Description / Purpose

The Pizza Sales Analysis Dashboard is a two-page interactive Power BI report developed to monitor business performance, analyze sales trends, and evaluate product performance.

The dashboard provides insights into revenue, order volume, pizza category preferences, pizza size distribution, and best- and worst-selling products, helping businesses make data-driven decisions.

🛠️ 3. Tech Stack

The dashboard was built using the following tools and technologies:

📊 Power BI Desktop – Main platform for creating interactive dashboards and visual reports.

📂 Power Query – Used for data cleaning, transformation, and preparation.

🧠 DAX (Data Analysis Expressions) – Used for calculated measures, KPIs, and analytical calculations.

📝 Data Modeling – Used to organize data and support interactive filtering and analysis.

📈 Data Visualization – Used to represent sales trends, category contributions, and product performance.

📁 File Formats – .pbix for the Power BI project and .png for dashboard screenshots.

✨ 5. Features / Highlights

🔹 A. Business Problem

Pizza businesses generate large volumes of transactional data, making it difficult to monitor sales performance, understand customer preferences, and identify high- and low-performing products.

Key business questions include:

Which days and months generate the highest number of orders?

Which pizza categories contribute the most revenue?

Which pizza sizes are preferred by customers?

Which pizzas generate the highest revenue?

Which products have the lowest sales and order frequency?

🔹 B. Goal of the Dashboard

To develop an interactive business intelligence solution that:

Monitors key sales performance indicators.

Identifies daily and monthly sales trends.

Analyzes category-wise and size-wise sales distribution.

Highlights best- and worst-selling pizza products.

Supports inventory planning and product performance evaluation.

Enables data-driven business decision-making.
